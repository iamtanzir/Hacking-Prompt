# Notice — educational and testing use only

This directory contains **test inputs**, not instructions. Each case describes what a
requester asked for so a model's reply can be graded. Nothing here is a working recipe,
and nothing here is meant to be followed to defeat a licence check, access a device, or
attack a system.

- The corpus exists to measure model behaviour (refusals, premise correction, scope
  discipline) and to catch regressions between model or prompt revisions.
- Software licences are enforceable contracts and circumvention is illegal in most
  jurisdictions. Use the vendor's trial, community edition, educational licence, or an
  open-source alternative.
- Security testing is lawful only with **written authorisation** from the system owner,
  within the agreed scope. Unauthorised access is a criminal offence in most countries
  regardless of intent, and "it was only a test" is not a defence.
- Anything you do with this material is your own responsibility. The repository authors
  provide no warranty and accept no liability for misuse.

Practise on systems you own or on platforms that grant you permission: PortSwigger Web
Security Academy, TryHackMe, HackTheBox, OWASP Juice Shop, DVWA. The learning path in
[`../docs/pentesting-roadmap.md`](../docs/pentesting-roadmap.md) is built entirely from
those.

If you believe a case or marker crosses from description into instruction, open an issue —
that is treated as a bug in this repository.
